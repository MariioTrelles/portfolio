# Mario Trelles Portfolio

Portfolio personal hecho con React, Vite y TypeScript.

## Scripts

- `npm install`: instala dependencias
- `npm run dev`: arranca el entorno local
- `npm run build`: valida TypeScript y genera la build en `dist/`
- `npm run preview`: previsualiza la build

## Estructura

- `src/`: aplicación y contenido del portfolio
- `public/`: archivos estáticos
- `public/cv/`: coloca aquí `Mario_Trelles_CV.pdf` para que funcione el botón de descarga
